# Hustle Kits: Brand and Document Style Standard

One standard for everything we write for the kits: documents, spreadsheets, and (where it applies) web pages. It is taken from the live site's CSS (`bbq-hustle/index.html`), so documents and sheets match the website.

Applied so far: the Meat Cost Calculator (all tabs), its guide "How to Use the Meat Cost Calculator", and (as a pilot) the Start Here document and the Brisket chapter. The rest of the master documents still need to be brought into line (see "Rollout" at the end).

## Palette

| Name | Hex | Use |
|---|---|---|
| Ink | `#241a14` | Body text, title bands, dark fills |
| Cream | `#f6ede1` | Page and sheet background, text on dark fills |
| Cream 2 | `#efe1cd` | Note bands, table row banding |
| Ember | `#c65d2e` | Section headings, accents, links, "filled in for you" text |
| Muted | `#5a4c3e` | Secondary text, notes, subtitles |
| Muted light | `#b3a290` | Borders, greyed-out cells, subtitle on dark band |
| White | `#ffffff` | Boxes the reader types in, table body rows |

## Fonts

- **Fraunces** for titles and headings.
- **Work Sans** for everything else.

## Documents (Google Docs, and any file exported from them)

| Element | Style |
|---|---|
| Page background | White (documents are printed, so no tint). Cream is for on-screen spreadsheets only |
| Title (Heading 1) | Fraunces 28 pt, bold, Ink |
| Subtitle | Work Sans 12 pt, italic, Muted |
| Section heading (Heading 2) | Fraunces 18 pt, bold, Ember, 1.5 pt Ember rule underneath, 24 pt above, 8 pt below |
| Sub-heading (Heading 3) | Fraunces 13 pt, bold, Ink, 14 pt above, 4 pt below |
| Body text | Work Sans 11 pt, Ink, line spacing 115%, 6 pt below |
| Bold | Work Sans bold, for lead-in phrases and key terms |
| Links | Ember, underlined |
| Tables | Header row Ink fill with Cream bold text 10.5 pt; body rows white and Cream 2 alternating; 0.75 pt Muted-light borders; 5 pt top and bottom cell padding, 6 pt left and right; first column bold |
| Lists | Plain bullets or numbers, body style, no extra decoration |

## Spreadsheets (Google Sheets)

| Element | Style |
|---|---|
| Sheet background | Cream, grid lines hidden |
| Title row | Ink fill, Fraunces 24 pt bold, Cream text |
| Subtitle row | Ink fill, Work Sans 11 pt, Muted-light text |
| Note row | Cream 2 fill, Work Sans 10 pt italic, Muted text |
| Section bar | Ember fill, Fraunces bold, Cream text |
| Table header | Cream 2 fill, Work Sans 10 pt bold, centered, Ember rule underneath |
| Cells the reader fills in | White, with a thin Muted-light border |
| Cells filled in automatically | Orange (Ember) italic text; the reader can type over them |
| Cells not needed | Grey text on Cream 2 |
| Sample row | Ember bold italic, marked SAMPLE |
| Warnings | Ember bold, starting with the warning sign |
| Result bar | Ink fill, Fraunces, Cream text |
| Numbers | Percentages `0%`, money `$#,##0.00`, weights one decimal |

## Naming and capitalization

- **Brisket is always capitalized**, in headings and in running prose, as if it were a proper name ("Rest the Brisket", "Texas-style Brisket").
- **Other menu items used as names are Title Case**, exactly as they appear in the calculator's item list: Pulled Pork, Pulled Chicken, Hot Dogs, Meatballs, Ribs, Smash Burger, Chicken Wings.
- **A count stays lowercase**: "3 meatballs each", "2 ribs per portion", "a hot dog".
- Titles and headings use sentence case ("Set up once: My Prices"), except the three names the whole kit shares: The BBQ Hustle, Build the Business, Master the Smoke.
- Tab, section and field names are written as they appear in the sheet, with their capitals.

## Writing

- Plain language. Short sentences. Say what to do first, then why.
- Money in US dollars. Weights in pounds and ounces. The kit's buyers are mostly American.
- Worked examples use numbers that have been checked against the calculator. Never invent a price, a statistic or an award.

## Rollout

Master set: the "2 BBQ Hustle" folder inside "BBQ Hustle - DELIVERY (staging)". The older duplicates in the main BBQ Hustle folder are not the master.

- Done: Start Here, the Brisket chapter, the Meat Cost Calculator and its guide.
- To do (Google Docs, awaiting approval of the pilot): Welcome, the Table of Contents, and the other nine Master the Smoke chapters.
- Leave alone: the Build the Business modules and worksheets (Word files, locked or approved; handled separately by the owner), and the Module 10 dashboard.
- Any web page copy is out of scope for now.

Page flow (documents): turn on widow/orphan control for the whole document; headings keep with the next paragraph and keep their lines together; short paragraphs (about 500 characters or less) keep their lines together, so they move to the next page instead of splitting. Use these settings instead of blank spacer paragraphs. Add a page break before a heading only when the owner asks.

How a chapter is restyled: real heading styles replace bold-only lines, empty spacer paragraphs are removed (no text changes), and the text is otherwise left exactly as written.
